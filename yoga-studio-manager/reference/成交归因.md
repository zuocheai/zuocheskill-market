# 成交归因判据

把一段段微信聊天，判成"成交/未成交/跟进中"，并给未成交的定位卡点。判据写死，别随手猜。

## 第一步：分组

一段对话归到一条"线索"。分组键（有哪个用哪个）：学员名/微信备注 → 咨询日期 → 课型。同一人多次聊天合起来看全过程。

## 第二步：判结果（三选一）

- **成交**：出现明确付费/办卡/约定上课的确认（"已转""付款了""报年卡""周六第一节见"）。
- **跟进中**：有意向、还没拒也没买（在问价、约时间、要再想想）。
- **未成交**：明确表示不报/搁置/联系不上且无后续（"最近没空""再看看吧""报了别家"）。

判不准写 **"存疑·信息不足"**，不硬归。

## 第三步：给未成交/跟进中贴原因码

| 码 | 原因 | 信号举例 | 下一步 |
|---|---|---|---|
| P1 | 价格 | 有点贵/超预算 | 算单次账+分期，别一味降价 |
| P2 | 时间排不开 | 没时间/下班晚 | 推晚班/小班/线上/灵活约 |
| P3 | 距离远 | 太远/不方便 | 上门/线上课 |
| P4 | 怕坚持不下来 | 买了怕不来 | 月卡先试/打卡返现/同伴机制 |
| P5 | 身体顾虑 | 腰不好能练吗 | 安排体测+针对性体验 |
| P6 | 要和家人商量 | 问下老公 | 给可转发介绍+限时钩，3天回访 |
| P7 | 在对比别家 | 也在看XX家 | 列差异点，不贬同行 |
| P8 | 只是问问 | 只问价不约体验 | 拉进体验课名单低压力跟进 |
| P9 | 体验课没约上 | 一拖再拖 | 直接给两个具体时间二选一 |
| P10 | 被课程/教练劝退 | 上完说太累 | 换课型或换教练再邀 |
| P11 | 联系不上 | 发出没回 | 换时段换话术，2次无回应转休眠 |

## 第四步：出报告（固定五段）

1. 一句话结论：N条，成交X/跟进Y/未成交Z，成交率，最集中的原因码。
2. 最该抢救的3条：跟进中、只差临门一脚，逐条给"卡点＋一句下一步"。
3. 未成交分布：按原因码统计，点出哪类改话术、哪类直接放弃省精力。
4. 可复用的教训：暴露的共性问题（如"体验课约不成是最大漏斗口"）。
5. 数据来源与免责：注明覆盖几条、哪个时间段；判不准的列"存疑"清单。

产出文件名 `归因报告_YYYYMMDD.md`。

> 说明：判得准取决于喂进来的记录全不全。个人微信没有官方批量导出接口，"把记录弄成文本"这一步靠老板自己复制粘贴或另接导出工具；本件负责拿到文本之后的判断与报告。
