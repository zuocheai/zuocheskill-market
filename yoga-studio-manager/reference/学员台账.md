# 学员台账细则

起步表：`../templates/学员台账空表.csv`（Excel/WPS 打开即填）。

## 字段

| 字段 | 填什么 | 干什么用 |
|---|---|---|
| 学员名/微信备注/手机号 | 认人 | 手机号是个人信息，仅本机存、不外传 |
| 卡种 | 年卡/季卡/次卡/私教N节/体验课 | 判续费节奏 |
| 报课日期/卡到期日 | 起止 | 到期提醒的关键 |
| 总课时/已耗课时/剩余课时 | 次卡·私教按节；团卡可填"—" | 催续费 |
| 上次上课/负责教练 | 最近一次·谁带 | 判活跃还是流失 |
| 状态 | 见下 | 自动重算得，别手动乱填 |

## 状态取值（由规则算出）

- `活跃`：正常在练。
- `课时告急`：剩余课时 ≤ 2 节 → 催续费。
- `将到期`：距卡到期 ≤ 14 天 → 给续费钩。
- `流失风险`：距上次上课 ≥ 14 天 且非已流失 → 软性促活。
- `已流失`：长期无联系。

## 每次改完，给老板一张"今日跟进清单"

格式：`谁 · 卡在哪(课时/到期/久未来) · 建议说什么`。改底表前先复制一份带日期留档。
