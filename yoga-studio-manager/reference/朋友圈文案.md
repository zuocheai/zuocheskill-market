# 朋友圈文案模板

骨架：**第一行钩住 → 说痛点/共鸣 → 给好处 → 一句行动指令**。一次出 2~3 条挑。想更像老板口吻，先请他贴 2~3 条以往朋友圈学了再写。`{馆名}{数字}` 留占位，老板填实。

**招生（拉新）**
> 下班腰像生了锈？别等疼了才想起身体。{馆名}新手友好，零基础也能跟着练，一节课下来肩是松的。本周还有{N}个体验名额，想来评论区扣1或私信我。

**续费/促销**
> {名字}们的年卡这周到一批续费名额，老学员价尽量给到位。与其下次犹豫来不来，不如先把时间锁住。私我"续费"，给你算笔单次账——比单买省{X}。

**促活（对久未到店·软性关心）**
> 好久没见你了，惦记。课给你留着，不用有压力，哪天想动了随时约。天冷，注意别硬撑。

**好评晒图（学员同意才发·名字打码）**
> "本来只想试试，结果连着来三个月，失眠都轻了。"——一位{年龄段}的姐姐。瑜伽不卷体式，卷的是你能不能对自己好一点、坚持下去。想体验的私信。

**教练介绍**
> 介绍位{教练}：带课{年数}年，最擅长{方向}(体态调整/孕产/理疗)，风格{温和/严谨/鼓励型}。想约她的课直接说"想约{教练}"。

## 注意
- 不写"包瘦/治好颈椎"这类夸大招纠纷的话。
- 用学员照片/评价先取得本人同意、打码。
- 要配海报走"海报"档；一键出图先确认（可能花钱）。
