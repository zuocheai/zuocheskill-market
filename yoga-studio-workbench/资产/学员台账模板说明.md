# 学员台账模板说明（模式1）

配套文件：`学员台账模板.csv`（含三行示例，用之前删掉示例行即可当空表用；Excel/WPS/记事本都能开）。

## 字段怎么用

- `学员名/微信备注/手机号`：认人。手机号是个人信息，只存老板自己发的、只在本机。
- `卡种`：年卡/季卡/次卡/私教N节/体验课 等。
- `总课时/已耗课时/剩余课时`：次卡或私教按节记；团卡可只记到期日、课时列填"—"。
- `卡到期日`：盯续费的关键列。
- `上次上课/负责教练`：判活跃还是快流失。
- `状态`：`活跃 / 将到期 / 课时告急 / 流失风险 / 已流失`——由下面三条重算得出，别手动随便填。

## 每次改完自动挑"今天该催谁"

1. **剩余课时 ≤ 2 节** → 标 `课时告急`，催续费。
2. **距卡到期 ≤ 14 天** → 标 `将到期`，给续费优惠钩。
3. **距上次上课 ≥ 14 天** 且非已流失 → 标 `流失风险`，发一条关心式促活（不是硬推销）。

挑出来的人单独列一张"今日跟进清单"发老板：`谁·卡在哪·建议说什么`。

## 改表纪律

- 每次动底表前先复制一份留档（文件名带日期）。
- 手机号、微信不写进会被公开的地方（台账不外传）。
