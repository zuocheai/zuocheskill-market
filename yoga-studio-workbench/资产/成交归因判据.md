# 成交归因判据（模式3 内核）

> 目的：把一段段微信聊天记录，判成"成交 / 未成交 / 跟进中"，并给未成交的**定位卡在哪一步**。判据写死，避免随手猜。

## 第一步：分组

一段对话先归到一条"线索"。分组键（有哪个用哪个）：学员名或微信备注 → 咨询日期 → 课型（团卡/私教/体验课）。同一个人多次聊天合成一条线索看全过程。

## 第二步：判结果（三选一）

- **成交**：对话里出现明确付费/办卡/约定上课的确认（"已转""付款了""报年卡""周六第一节见"）。
- **跟进中**：有意向、还没拒、也还没买（在问价、约时间、要再想想）。
- **未成交**：明确表示不报/搁置/联系不上且无后续（"最近没空""再看看吧""报了别家"）。

判不准时写 **"存疑·信息不足"**，不硬归（红线：不伪造）。

## 第三步：给未成交/跟进中的贴"原因码"

| 码 | 原因 | 对话里的信号（举例） | 下一步动作 |
|---|---|---|---|
| P1 | 价格 | "有点贵""能便宜吗""超预算" | 给分期/体验价/算单次账，别一味降价 |
| P2 | 时间排不开 | "没时间""下班晚""周末带娃" | 推小班/晚班/线上/灵活约课 |
| P3 | 距离远 | "太远了""不方便来" | 上门/附近场馆/线上课 |
| P4 | 怕坚持不下来 | "买了怕不来""三分钟热度" | 月卡先试/打卡返现/同伴机制 |
| P5 | 身体顾虑 | "我腰不好能练吗""零基础" | 安排体测+针对性私教体验 |
| P6 | 要和家人商量 | "问下老公""得跟家里说" | 给可转发的介绍+限时钩，3天回访 |
| P7 | 在对比别家 | "也在看XX家""你们比他们贵在哪" | 列差异点(师资/环境/距离/课量)，不贬同行 |
| P8 | 只是问问 | 只问价不接约体验课 | 培育：拉进体验课名单，低压力跟进 |
| P9 | 体验课没约上 | 答应约体验却一拖再拖 | 直接给两个具体时间二选一 |
| P10 | 被教练/课程劝退 | 上完体验说太累/不适合 | 换课型或换教练再邀一次 |
| P11 | 联系不上 | 发出去没回 | 换时段换话术，2次无回应转"休眠" |

## 第四步：出报告（固定五段）

1. **一句话结论**：这批N条，成交X、跟进中Y、未成交Z；成交率多少；最集中的卡点是哪个原因码。
2. **最该抢救的3条**：跟进中且有意向、只差临门一脚的，逐条给"卡点＋一句下一步"。
3. **未成交分布**：按原因码统计（例：价格5条、时间3条、只是问问6条），点出哪类值得改话术、哪类直接放弃省精力。
4. **可复用的教训**：这批暴露的共性问题（如"体验课约不成是最大漏斗口"）。
5. **数据来源与免责**：注明喂进来的记录条数、时间范围；判不准的列"存疑"清单。

产出文件名：`归因报告_YYYYMMDD.md`，落本件 `示例产出/` 或老板指定目录。
