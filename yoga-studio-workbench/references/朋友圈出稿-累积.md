# 朋友圈文案 · 好稿沉淀

> **用法**：每次出稿，老板挑中满意的那版，**追加到下面**。
> 攒多了就能看出"什么招在他店里管用"，下次直接复用。
> **这也是这个 skill 越用越强的地方。**

---

## 沉淀格式（每次加一条）

```
### 〔用途〕____（拉新 / 续费 / 日常人设 / 活动通知）
【发的时间】
【为什么好 —— 一句话】
【正文】
  钩子：
  痛点：
  解法+亮点：
  行动：
【以后怎么复用】
```
