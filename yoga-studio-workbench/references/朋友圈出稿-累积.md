# 朋友圈文案 · 好稿沉淀

> **用法**：每次出稿，老板挑中满意的那版，**追加到下面**。
> 攒多了就能看出"什么招在他店里管用"，下次直接复用。
> **这也是这个 skill 越用越强的地方。**
> ⚠️ **只沉淀方法（可复用的切口、结构、踩过的坑）**——**不要写进店名、地址、价格、学员数等真实经营数据**，那是老板自己的隐私，本文件只留在他本机。

---

## 沉淀格式（每次加一条）

```
### 〔用途〕____（拉新 / 续费 / 日常人设 / 活动通知）
【发的时间】
【为什么好 —— 一句话】
【正文】
  钩子：
  痛点：
  解法+亮点：
  行动：
【以后怎么复用】
```

# 好稿库

## 〔活动招生〕"怕被评价"切口（已验证有效）

【发的时间】节假日活动期间

【为什么好】用顾客自己的话当钩子（"怕的不是练不动，是怕被盯着看动作做错"），比店方自夸更容易被认领；再用开店年数/学员数/教练教龄做信任背书。

【正文模板】（把 `{}` 换成这家店的真数字）

钩子：
「我怕的不是练不动，是怕被盯着看动作做错。」

痛点：
零基础第一节课就被人盯着练，动作做错了就放弃了。

解法+亮点：
零基础进来的第一节课不教动作，先学呼吸和发力感，**没有一个动作是要求你立刻做到的**，练成什么样都行。
教练教龄 {} 年，风格是那种——你做错了她先蹲下来跟你说话，不是喊你"再坚持一下"。
开了 {} 年，{} 个学员在读。

行动：
私我"体验"两个字，不收定金，先来上一节试试。

价格：
{} 元 = {} 次体验 ‖ 或 {} 次私教（二选一）

【以后怎么复用】
- **"怕被评价"是这类场馆的招牌切口**——零基础客群通用，可长期复用
- 数字资产（开业年数 / 学员数 / 教龄）**先备好存在门店档案里**，下次活动直接当背书，不用临时问
- 让顾客自己说出那句痛点，比你替他说更有分量

## 踩过的坑（下次直接绕）

### 一、内容层

- **⚠️ 别编学员案例。** 初稿写了"某四十多岁姐姐健身房练过两次"，被要求删除——**学员反馈、瘦了多少斤、教学年限，没老板给就不能编**，编出来的是虚假信息。案例要用就问他要，他说没有就写"暂无真实案例"。

### 二、交付前必查

- [ ] 违禁词逐字过了吗（第一/最好/全城最低/保证瘦/根治/治疗…）
- [ ] **价格写明含什么、不含什么了吗**（含不含体测、每节多少分钟）——防虚假宣传
- [ ] 学员照片/评价：本人同意了吗？名字打码了吗？
