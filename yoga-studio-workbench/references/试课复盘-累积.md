# 试课复盘 · 累积档案

> **用法**：每周做一次，**往下面追加**，别删旧的。
> **这是这个 skill 最有价值的产出** —— 跑满四周，老板自己就能看出规律。

---

## 复盘要出的六条（每轮都要齐）

| 输出 | 要求 |
|---|---|
| **真实卡点** | 不是"价格贵"，是他**说了什么**让你判断出嫌贵 |
| **在哪一步失手** | 报价时机早/晚、没问需求就推销、答得太笼统 |
| **可复用的改法** | 下次这句话怎么说，**抄得走** |
| **该追还是该放** | 明确分成"还能追"和"别追了" |
| **同类信号** | 这周这几个人的共同点 |
| **待验证的猜想** | **标明是猜的**，不当结论 |

**每条都要指得回老板给的原话。**

---

## 四周后看这里

跑满四周，回头看第一节的结论，**回答这个问题**：

> **哪一句说法最常见地砸单？**

这比任何软件给的"转化率"都有用——因为那是他的店、他的学员、他的原话。
