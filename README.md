# zuocheskill-market · 左车成品技能货架

装**能帮人解决某个具体问题的独立技能**（跟 `zuocheskill` 框架仓库分开：那边是搭知识库的框架，这边是一个个成品技能）。

**一个技能 = 一个顶层文件夹**，里面自带 `SKILL.md`（技能说明）＋上手卡＋参考资料＋模板。把整个文件夹下载／放进你自己的 AI 技能目录即可用。
